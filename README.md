# FlyRank Internship - W5 A9: The Polite Scraper

## Target Classification
- **Target Site:** Books to Scrape (https://books.toscrape.com)
- **Purpose:** A publicly available sandbox environment explicitly created for testing and practicing web scraping.
- **Scope:** First 3 catalogue pages only (60 unique books total).
- **Data Collected:** Book title, product URL, raw price text, availability, rating, description, source page, fetch timestamp, and normalized price.
- **Robots.txt Analysis:** A request to `https://books.toscrape.com/robots.txt` returns `404 Not Found` (no robots file found).
- **Ethical Commitment:** I will not reuse this code on another site without checking its rules and terms first.
